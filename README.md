# sql-marketing-analytics
# Аналіз ефективності маркетингових каналів та оптимізація CAC

## 📌 Огляд проєкту
Цей проєкт присвячений аналізу сирих кумулятивних даних із рекламних кабінетів трьох джерел (Meta, TikTok, Google). Головна аналітична задача — очистити дані від ефекту накопичувального підсумку (кумулятивності), розрахувати ключові метрики маркетингової воронки (CPM, CTR, CR, CAC) та оцінити рентабельність каналів за допомогою метрики LTV/CAC.

## 🛠️ Технічний стек та методи
* **База даних:** Google BigQuery (SQL)
* **Функції та підходи:**  Віконні функції `ROW_NUMBER() OVER()` для дедублікації та очищення щоденних зрізів (snapshots).
  * Віконна функція `LAG() OVER()` для розрахунку чистих щоденних дельт (приросту витрат та метрик воронки).
  * СРТ (Common Table Expressions / `WITH`) для побудови чистої та читаємої архітектури запиту.
  * Безпечне ділення через `NULLIF()` для запобігання помилкам ділення на нуль.

## 📊 Основні бізнес-результати та інсайти

1. **Найефективніший канал (CAC):** Найнижчу вартість залучення користувача демонструє **Meta (CAC = $3.11)**. Це в 1.7 раза дешевше за TikTok ($5.39) та в 4.5 раза дешевше за Google ($14.12).
2. **Аналіз рентабельності (LTV/CAC):**
   * **Meta (LTV/CAC = 2.00)** — найприбутковіший канал, кожен долар повертає два долари доходу.
   * **TikTok (LTV/CAC = 1.58)** — рентабельний канал, показує стабільний ріст.
   * **Google (LTV/CAC = 0.88)** — **збитковий канал**. Витрати на залучення перевищують життєвий цикл цінності користувача.
3. **"Вузьке місце" воронки:** Для всіх каналів головною проблемою є етап `Click -> Install` (конверсія з кліку в установку додатка), яка становить лише 30-40%. Натомість етап `Install -> Registration` працює ідеально (87-96%).

## 💡 Стратегічні рекомендації
* **Перерозподіл бюджету:** Рекомендується скоротити інвестиції в збитковий канал Google і перенаправити вивільнений бюджет на масштабування високоефективного каналу Meta.
* **Продуктова оптимізація:** Необхідно провести A/B тестування сторінки додатка в маркетах (ASO), щоб підняти конверсію з кліку в інсталл, особливо для TikTok, де вона найнижча (30.96%).
* **Стабільність кампаній:** Помісячний аналіз показав повну стабільність CAC протягом січня-липня, що свідчить про прогнозованість каналів залучення.
